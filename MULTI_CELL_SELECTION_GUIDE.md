# 🎯 Multi-Cell Selection Guide

## ✨ You Already Have This Feature!

The meal planning grid **already supports multi-cell selection** to add the same meal to multiple cells at once!

---

## 🚀 How to Use Multi-Cell Selection

### **Step 1: Select Multiple Cells**

**On Mac:**
- Hold **Cmd** (⌘) and click cells

**On Windows/Linux:**
- Hold **Ctrl** and click cells

**What happens:**
- First click: Cell gets indigo border and background
- Each additional Cmd/Ctrl+click: Adds or removes cells from selection
- Selected cells show: **Indigo background + Indigo border + Ring**

### **Step 2: Selection Toolbar Appears**

Once you select cells, a toolbar appears at the top:

```
┌─────────────────────────────────────────────────────────┐
│  [3] 3 cells selected                                   │
│  Cmd/Ctrl + click to select more cells                  │
│                                                          │
│  [Type meal name...]  [Clear]                           │
└─────────────────────────────────────────────────────────┘
```

### **Step 3: Add Meal to All Selected Cells**

**Option A: Type a custom meal**
1. Type meal name in the input field
2. Press **Enter**
3. ✅ Meal is added to ALL selected cells!

**Option B: Choose from suggestions**
1. Start typing (e.g., "Scr...")
2. Dropdown shows matching recipes and previous meals
3. Use **Arrow keys** to navigate
4. Press **Enter** to select
5. ✅ Meal is added to ALL selected cells!

### **Step 4: Clear Selection**

- Click **"Clear"** button
- Or press **Escape**
- Or the selection auto-clears after adding a meal

## ❓ Troubleshooting

### **Issue: Cells don't select when I click**

**Solution:** Make sure you're holding **Cmd** (Mac) or **Ctrl** (Windows/Linux)

### **Issue: Toolbar doesn't appear**

**Solution:** 
- Make sure at least 1 cell is selected
- Check if toolbar is at the top of the page
- Scroll up if needed

### **Issue: Meal doesn't add to all cells**

**Solution:**
- Make sure you pressed Enter
- Check console for errors
- Verify meal plan exists for the week
