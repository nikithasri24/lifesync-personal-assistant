📋 All Modal Designs

Complete modal specifications with terracotta theme

Modal Behaviors

Add Item Modal

• Slides up from bottom with backdrop blur
• Three large tap targets for Barcode/Voice/Manual
• Each option has terracotta circular icon, title, and description
• Drag handle at top for pull-to-dismiss
• Tap backdrop to dismiss

Manual Entry Form Modal

• Full-height modal with scrollable content
• Fields: Item Name*, Quantity, Unit, Store, Category, Price, Notes
• Beige input backgrounds with terracotta borders on focus
• Terracotta gradient "Add to List" button at bottom
• Auto-focus on Item Name field
• Real-time validation

Edit Item Modal

• Same form as manual entry, pre-filled with item data
• Additional "Delete" button at bottom (outlined red)
• "Save Changes" button (terracotta gradient)
• Opens when user taps an existing item

Barcode Scanner Modal

• Full-screen camera view
• Scanning reticle overlay in center
• "Cancel" button top-left (white text)
• Haptic feedback on successful scan
• Auto-dismiss and show manual form with data

Voice Input Modal

• Center modal with pulsing microphone icon
• "Listening..." text below icon
• Live transcript appears as user speaks
• "Done" button when transcript detected
• Terracotta pulsing animation during recording

Pantry Item Detail Modal

• Shows: Name, Category, Stock level, Expiry date, Location
• Stock adjustment buttons (+/-)
• "Add to Shopping List" button if stock low
• "Mark as Expired" button (red)
• Edit and Delete options

💻 Technical Implementation Notes

Key considerations for development

Component Architecture

Main Components

ShoppingSmart.tsx
├── ShoppingHeader (title, subtitle, icons)
├── SegmentedControl (List | Pantry | Stores)
├── ShoppingListView
│ ├── ShoppingItem (minimal card)
│ └── EmptyState
├── PantryView
│ ├── CategorySection
│ ├── PantryGrid (3 columns)
│ └── PantryCard
├── StoresView
│ └── StoreCard (rich stats)
├── AddItemModal
│ ├── AddMethodChoice
│ ├── ManualEntryForm
│ ├── BarcodeScannerModal
│ └── VoiceInputModal
├── EditItemModal
└── TerracottaFAB

State Management

• React Query for shopping items, pantry items, stores
• Local state for active segment (List/Pantry/Stores)
• Modal state for showing/hiding modals
• Form state for add/edit item forms
• Real-time sync via Supabase subscriptions

Animations

• Modal transitions: Slide up from bottom (300ms ease-out)
• Checkbox fill: Scale + fill gradient (200ms ease-in-out)
• Segment change: Smooth background slide (250ms cubic-bezier)
• List item add: Fade in + slide down (350ms ease-out)
• Swipe actions: Transform X with spring physics
• FAB press: Scale down to 0.95 on active (100ms)

Mobile Optimizations

• Touch targets minimum 44x44px (iOS guidelines)
• Checkboxes 32px for easy thumb tapping
• Prevent scroll bounce on modals
• Safe area insets for iPhone notch/home indicator
• Haptic feedback on checkbox toggle
• Debounced voice input to prevent premature submission
• Lazy load pantry grid items for performance
