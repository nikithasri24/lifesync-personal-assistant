✨ Key Design Features

💰 Dashboard Overview

  • Income, Expenses, Cashflow metrics
  • Net Worth with assets/debts breakdown
  • Top spending categories with bars
  • Month-over-month comparisons
  • Month navigation for historical data

🏦 Account Management

  • Grouped by type (Cash, Credit, Investment, Loans)
  • Color-coded left borders by category
  • Balance and institution display
  • Credit utilization visualization
  • Investment gains/losses tracking

📋 Transaction History

  • Grouped by date (Today, Yesterday, This Week)
  • Emoji icons for categories
  • Credit transactions in green
  • Debit transactions in default color
  • Merchant name and category display

📊 Budget Tracking

  • Category-based monthly budgets
  • Visual progress bars with percentages
  • Over-budget alerts in red
  • Remaining amount calculations
  • Total budget summary card

🎨 Visual Hierarchy

  • Terracotta gradients for primary metrics
  • Green for income and gains
  • Red for debts and over-budget
  • Consistent card-based layouts
  • Clear section groupings

🔄 Month Navigation

  • Arrow buttons for month switching
  • Current month prominently displayed
  • Historical data access
  • Consistent across all tabs
  • Sticky navigation bar
