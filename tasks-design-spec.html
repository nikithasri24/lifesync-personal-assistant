✨ Key Design Features

📋 Status Grouping

  • Kanban-style vertical sections
  • To Do, In Progress, Waiting, Done
  • Task count badges per section
  • Clear visual separation
  • Mobile-friendly vertical scrolling

🎯 Priority System

  • Color-coded priority badges (High/Medium/Low)
  • Left border color indicates priority
  • Red for high priority tasks
  • Orange for medium priority
  • Green for low priority

✅ Task Details

  • Checkbox for quick completion
  • Tags for categorization (Work, Personal, etc.)
  • Due dates and time estimates
  • Subtask progress (3/5 completed)
  • Project assignment display

📁 Projects

  • Project cards with progress bars
  • Task count and completion percentage
  • Color-coded project borders
  • Quick project overview
  • Project-based task grouping

🔍 Filters

  • Quick filter pills (All, Inbox, Upcoming, Starred)
  • Section-based navigation
  • Active filter highlighting
  • Horizontal scrolling filter bar
  • Easy filter switching

🎨 Visual Hierarchy

  • Terracotta theme throughout
  • Completed tasks shown with lower opacity
  • Strikethrough for completed task titles
  • Green checkmarks for completion
  • Consistent card-based layouts
